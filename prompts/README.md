# Prompts operacionais

Esta pasta contém templates reutilizáveis para orientar sessões no Codex ou no ChatGPT Work.

## Templates

- [Executar somente a próxima Issue da MVP](executar-proxima-issue-mvp.md)

Esses arquivos descrevem um processo de trabalho, mas não são solicitações ativas por si mesmos. Em cada sessão, prevalecem a solicitação atual do usuário, o `AGENTS.md`, a Issue selecionada e o estado real do repositório e do GitHub.
