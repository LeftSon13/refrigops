# Documentos históricos

Esta pasta preserva apenas documentos históricos adequados à publicação e úteis para explicar a evolução do projeto.

Materiais históricos de descoberta que contenham contexto operacional específico são mantidos fora do repositório público. A documentação pública registra somente conclusões abstratas e dados sintéticos.

Se houver valor educacional a preservar, ele deverá ser apresentado em outro documento, totalmente reescrito e sintético, sem copiar detalhes de instalações reais.

Documentos históricos não são a fonte de verdade automática do estado atual. Consulte primeiro o código, o Git, os testes e [`docs/11-contexto-atual.md`](../11-contexto-atual.md).
