# MVP v0.1

Esta pasta concentra a baseline específica, o backlog e o mapa de publicação da MVP demonstrativa v0.1.

## Documentos

- [Documento Mestre da MVP v0.1](documento-mestre-v0.1.md): definição da MVP, requisitos, limites, decisões e critérios de sucesso.
- [EPIC e backlog da MVP v0.1](epic-e-backlog-v0.1.md): decomposição planejada e rastreabilidade das Issues.
- [Mapa de publicação no GitHub](mapa-publicacao-github-v0.1.md): apoio operacional para relacionar a EPIC e as Issues publicadas.

O estado atual do software continua sendo confirmado pelo checkout, pelas migrations e pelos testes. Uma descrição planejada aqui não comprova que a funcionalidade já foi implementada.

## Mapa de autoridade

Para interpretar a MVP, consulte na seguinte ordem:

1. o Documento Mestre desta pasta, aprovado para o recorte de produto;
2. decisões de produto e ADRs aplicáveis;
3. a Issue atual e suas dependências;
4. código, migrations e testes para o comportamento realmente existente;
5. [`docs/11-contexto-atual.md`](../11-contexto-atual.md) para o checkpoint e o próximo passo permitido.

Auditorias datadas e documentos históricos fornecem evidência e origem, mas não substituem a verificação atual. Prompts em `prompts/` orientam o processo e não são solicitações ativas por si mesmos.
